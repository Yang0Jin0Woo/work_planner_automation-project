Business Planning Assistant

문서를 실행 계획으로 바꾸는
Spring Boot MVP

PDF 문서를 업로드하면 AI가 핵심 요약, 목표, 실행 과제, 리스크, 추가 확인 항목까지 구조화된 실행 계획 초안을 생성합니다. 생성된 결과는 브라우저에서 수정한 뒤 다시 검토할 수 있습니다.

1. 업로드 PDF 중심 분석, PPT/PPTX는 업로드 후 안내 메시지 제공
2. AI 구조화 Responses API와 Structured Outputs 기반 JSON 결과
3. 수정 브라우저에서 실행 계획 초안을 바로 편집

문서 업로드

PDF는 바로 분석합니다. PPT/PPTX는 1차 MVP에서 업로드 후 안내 메시지를 제공합니다.

업로드 가능한 최대 파일 크기는 25MB입니다.
